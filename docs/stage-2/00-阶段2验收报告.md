# Stage 2 验收报告

## 阶段目标

把 Stage 1 的“连接”升级成“已认证玩家会话”，并增加 Heartbeat、Idle Timeout 与在线状态观测。

## 任务完成矩阵

| 阶段任务 | 实现位置 | 状态 |
|---|---|---|
| Authentication Hook | `internal/auth` + `gateway.WithAuthenticator` | 完成 |
| ConnID/UserID/SessionID | `Connection` + `session.Session` | 完成 |
| Session Manager | `internal/session` | 完成 |
| 重复登录策略 | New Login Wins | 完成 |
| Heartbeat | MessageType 12/13 + Server scanner | 完成 |
| Idle Timeout | `HeartbeatCheckInterval` / `IdleTimeout` | 完成 |
| 在线状态 Metrics | sessions/auth/heartbeat timeout | 完成 |

## 阶段测试逐项验收

- 正确 Token：通过；
- 错误/过期 Token：通过；
- 同账号重复登录：通过，新登录替换旧连接；
- 心跳正常：通过；
- 心跳停止：通过；
- 网络半开模拟：通过；
- Close 与 Heartbeat 并发：通过。

## 阶段验收条件

- 未认证连接不能发送业务消息：**PASS**；
- Session 与 Connection 生命周期一致：**PASS**；
- 僵尸/半开连接在预期时间内回收：**PASS**；
- 重复登录行为符合 New Login Wins 文档：**PASS**；
- 无明显 goroutine 泄漏：**PASS**（heartbeat scanner 由 Server.Close 显式停止并 Wait；Connection goroutine 均由 Wait 回收）。

## 结论

**Stage 2：PASS。**

Stage 3 才允许进入 Backend 路由与 gRPC 内部接口实现。
