# Stage 2 测试报告

## 测试覆盖

### 鉴权

- 有效 Token：创建 UserID/SessionID 并进入 ACTIVE；
- 非法 Token：返回 `invalid_token`，不创建 Session；
- 过期 Token 模拟：Authenticator 拒绝，行为与非法 Token 一致；
- 重复鉴权：返回 `already_authenticated`。

### Session

- Session 注册/查询/终止；
- 同 UserID 二次登录替换旧 Session；
- 64 个 goroutine 并发注册同一 UserID，最终只有一个 ACTIVE winner；
- Connection Close 只按 ConnID 终止自己对应的 Session。

### 未认证业务消息

- `MessageType >= 1000` 在未认证状态被拒绝；
- 拒绝后连接仍可完成合法鉴权，证明消息没有进入错误响应队列污染后续协议顺序。

### Heartbeat / Idle Timeout

- 已认证连接周期发送 HeartbeatRequest 时保持在线；
- 停止心跳后在预期 IdleTimeout 内被关闭；
- 半开 transport（Read 永久阻塞）由 heartbeat scanner 主动回收；
- Close 与 heartbeat scanner 并发调用保持幂等。

### Stage 1 回归

继续覆盖：

- 单客户端连续收发；
- 多客户端并发；
- 非法 Envelope；
- 超大包；
- 客户端主动关闭；
- 服务端主动关闭；
- 慢客户端有界 Send Queue。
