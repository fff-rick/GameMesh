## 4. 阶段验收逐项检查

### 无无限队列

PASS。每个 Connection 的 Send Queue 在构造时固定容量，默认 256；满时 `Enqueue` 返回 `ErrSendQueueFull`。慢客户端专项测试证明队列不会突破容量。

### 连接关闭后资源能够回收

PASS。客户端主动关闭和 Server 主动关闭后，Connection 都从 registry 中移除，I/O goroutine 结束；测试等待 ConnectionCount 回到 0。

### 非法客户端不能导致进程 panic

PASS。malformed Envelope 被拒绝；连接仍可继续处理后续合法 Envelope。超大 frame 则受控关闭当前 Connection。

### race detector 无已知竞态

PASS。第一次 race run 找到 Connection 发布时序竞态，修复后完整 `go test -race ./...` 通过。

### 第一份并发连接与消息吞吐基线

PASS。50 并发客户端、10,000 条 256-byte Echo，0 failures；本机 loopback 测得约 105,963 msg/s，P95 约 0.80 ms，P99 约 2.15 ms。详细机器规格和限制见 `03-性能基线.md`。

## 5. 边界检查

- Resume Token。

这些分别属于阶段 2 及以后，未提前开发。
