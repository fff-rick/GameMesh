# 阶段 1：第一份性能基线

## 1. 基线性质

这是**开发容器内 loopback 基线**，用于后续阶段同环境回归比较；不是生产容量承诺，也不能据此宣称公网环境可达到相同连接数、延迟或吞吐。

## 3. 场景

执行：

```bash
go run ./cmd/bench -clients 50 -messages 200 -payload 256
```

- 并发 Client：50
- 每 Client 消息：200
- 总成功 Echo：10,000
- Payload：256 bytes
- 每条请求等待对应 EchoResponse 后再发送下一条

## 5. 解释

- 该结果证明 Stage 1 已能输出可复现的连接/消息性能基线。
- 数据主要反映当前实现与本机 loopback 条件，不包含真实网络 RTT、TLS、鉴权、Session、Backend RPC 等后续成本。
- 后续阶段必须保留相同参数回归，并增加 Stage 0 定义的 Idle Connections、Connection Churn、Slow Client、Burst 等场景。
- 不以“10 万连接”为当前成功标准。
