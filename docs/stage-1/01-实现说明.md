# 阶段 1：实现说明

## 1. 阶段目标

阶段 1 只建立最小可工作的 `Client <-> Gateway` 通道，解决连接、收包、发包和关闭。没有引入 Authentication、Session、Heartbeat、Backend/gRPC、Redis、可靠消息或断线恢复。

## 2. 实现范围

### WebSocket 接入

- 路径：`GET /ws`
- 实现：`internal/ws`
- 支持 RFC 6455 Upgrade、客户端 masking、服务端二进制 frame、Close/Ping/Pong。
- Stage 1 只接受 Binary Message；Text Message 视为协议错误。
- 为保证项目离线可构建，本阶段 WebSocket 层使用 Go 标准库实现最小 RFC 6455 子集，不依赖第三方模块。

### Connection 生命周期

状态遵循 Stage 0：

```text
NEW -> OPEN -> CLOSING -> CLOSED
```

每个 Connection：

- 使用随机 128-bit `ConnID`；
- 拥有一个 read loop 和一个 write loop；
- `Close` 通过 `sync.Once` 保证幂等；
- Server 使用受锁 registry 维护当前连接；
- Connection 关闭后从 registry 删除；
- Server Close 会关闭并等待所有已发布 Connection。

Race detector 曾发现 “Shutdown 与 WaitGroup.Add 并发” 的发布时序问题；最终实现改为在 Connection 对 Server 可见前固定 goroutine 计数，再启动 I/O goroutine，修复后 `go test -race ./...` 通过。

### 统一 Envelope

契约文件：`api/proto/envelope.proto`。

字段：

- Version
- MessageType
- RequestID
- MessageID
- Seq
- Ack
- Payload
- TimestampUnixMS

`internal/protocol` 使用 Protocol Buffers wire format 实现编码/解码，不依赖 `protoc` 或运行时第三方库。Stage 1 只实现两个 Gateway transport test control type：

- `1 = EchoRequest`
- `2 = EchoResponse`

`1000+` 预留为 opaque business message type。Echo 仅用于阶段 1 验证收发链路，不属于游戏业务逻辑。

### 包大小限制

沿用 Stage 0 冻结值：客户端边界单个完整 Envelope 最大 wire size 为 **64 KiB**。

WebSocket frame payload 超过上限时，读取层直接返回错误并关闭当前 Connection，不继续解析 Payload。

### 有界 Send Queue

默认容量：**256 条/Connection**。

业务/控制处理只能调用 `Connection.Enqueue`，不能直接写 socket。队列满时立即返回 `ErrSendQueueFull`，不存在无限扩容。当前 Echo 链路遇到队列满会关闭慢客户端；更细粒度 Drop/Coalesce 策略留到阶段 7。

### 结构化日志

主程序使用 `log/slog` JSON Handler，连接日志包含 `gateway_id`、`conn_id` 和关闭 reason。

### Connection Metrics

路径：`GET /metrics`，Prometheus text exposition。

阶段 1 已启用：

- `game_gateway_connections`
- `game_gateway_connections_total`
- `game_gateway_disconnects_total`
- `game_gateway_messages_received_total`
- `game_gateway_messages_sent_total`
- `game_gateway_message_bytes_received_total`
- `game_gateway_message_bytes_sent_total`
- `game_gateway_send_queue_depth_max`

没有使用 UserID/SessionID/ConnID 等高基数 label。

## 3. 运行

```bash
go run ./cmd/gateway -listen :8080 -gateway-id gateway-1
```

接口：

```text
ws://127.0.0.1:8080/ws
http://127.0.0.1:8080/healthz
http://127.0.0.1:8080/metrics
```
