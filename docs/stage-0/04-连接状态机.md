# 阶段 0：Connection 状态机

## 1. 状态

``` text
NEW -> OPEN -> CLOSING -> CLOSED
  \-------> CLOSING
```

  状态      含义
  --------- ----------------------------------------------------
  NEW       Conn 对象已创建，但接入握手尚未完成
  OPEN      可读写；后续阶段中仍需受鉴权/Session 状态限制
  CLOSING   已决定关闭；停止接受新的业务发送，允许执行有限清理
  CLOSED    终态；socket、goroutine、queue 等资源应已释放

## 2. 转换

  ------------------------------------------------------------------------------------
  当前              事件              下一状态          唯一动作
  ----------------- ----------------- ----------------- ------------------------------
  NEW               transport         OPEN              分配/确认
                    handshake success                   ConnID，启动受控读写生命周期

  NEW               handshake fail /  CLOSING           记录原因，释放已申请资源
                    server shutdown                     

  OPEN              client close      CLOSING           停止新写入，传播 disconnect

  OPEN              read/write fatal  CLOSING           记录错误，传播 disconnect
                    error                               

  OPEN              protocol fatal /  CLOSING           拒绝并关闭
                    oversize                            

  OPEN              idle timeout      CLOSING           标记 timeout，传播 disconnect

  OPEN              server close /    CLOSING           进入 Drain/关闭流程
                    shutdown                            

  CLOSING           cleanup complete  CLOSED            释放
                                                        transport、queue、goroutine

  CLOSED            任意事件          CLOSED            幂等，无副作用
  ------------------------------------------------------------------------------------

## 3. 并发约束

-   Close 必须幂等。
-   多个 goroutine 同时触发关闭，只能有一个关闭流程拥有最终清理权。
-   CLOSING 后禁止无限制向 Send Queue 写入。
-   CLOSED 后 Write 必须返回受控错误，不能 panic。
-   Connection 关闭事件必须能够通知 Session 层，但 Connection 不决定
    Session 是否最终销毁。

## 4. Shutdown

Gateway Shutdown 时：

``` text
Accepting
  -> Stop Accept
  -> OPEN connections receive shutdown/drain policy
  -> CLOSING
  -> CLOSED
```

阶段 7 才实现完整 Drain；阶段 0 先冻结状态结果：Shutdown 不允许产生新的
OPEN Conn，已有 Conn 最终都必须到 CLOSED。
