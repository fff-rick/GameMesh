## 4. 阶段验收逐项检查

### 所有状态转换均有文档

通过。Connection 与 Session 均有状态定义、转换表、终态和 Shutdown 行为。

通过。Gateway

通过。协议契约明确 `UNRELIABLE` 与 `COALESCIBLE`

### 已建立性能测试记录模板

通过。已定义机器规格、运行环境、Git

## 5. 阶段 0 冻结决策

1.  第一版客户端 Envelope 最大 wire size：**64 KiB**。
2.  Gateway 内部单条 RPC 消息建议上限：**256 KiB**。
3.  重复登录默认策略：**New Login Wins**。
4.  阶段 2-4 未启用 Resume 时，断连使 ACTIVE Session 直接 TERMINATED。
5.  阶段 5+ 启用 `DISCONNECTED_GRACE` 与 Resume。
6.  Backend 故障默认不改变 ACTIVE Session 身份状态。
7.  Metrics 禁止使用 UserID/SessionID/ConnID/RequestID/RoomID 作为
    Prometheus label。
8.  阶段 0 不写业务实现；阶段 1 才开始 WebSocket Connection Layer。
