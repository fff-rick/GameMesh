# Gateway v1：架构与状态机摘要

```text
Client WebSocket
       |
Connection (bounded send queue, per-connection rate limit)
       |
Session / Reliability / Resume
       |
Router -> Backend RPC                 Redis Presence (optional)
       |                                      |
Game service                         User -> Gateway lease
```

Gateway 只做接入、鉴权、协议、路由与传输可靠性，不解释业务 Payload 或维护游戏世界。

## 关键状态

Connection：`NEW -> OPEN -> CLOSING -> CLOSED`。每连接只有读、写两个固定生命周期 goroutine；所有出站写经有界队列。

Session：`AUTHENTICATED -> DISCONNECTED_GRACE -> AUTHENTICATED | EXPIRED`。同一 User 最后一次成功认证获胜；Resume Token 一次性轮换。

Presence：启用 Redis 时每个活跃连接持有 `User -> Gateway/Conn` 短租约。Claim/Renew/Release 都按随机 LeaseToken 条件执行，旧节点无法删除或续租新 Owner。

Shutdown：`SERVING -> DRAINING -> CLOSED`。Drain 拒绝新 Upgrade 与新业务请求，让已经接收的工作完成到 deadline；deadline 后关闭剩余连接并释放本地状态和 Lease。

完整的 Envelope、错误、Connection、Session 与可靠消息定义分别保留在 `docs/stage-0`、`docs/stage-4` 与 `docs/stage-5`，本文件不复制或改变其语义。
