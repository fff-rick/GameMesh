# Stage 3：测试报告

## 测试覆盖

### 路由

- 正常 `MessageType -> BackendType -> User -> Room -> Instance`；
- 未知 MessageType；
- User -> Room 缺失；
- Room -> Instance 缺失；
- BackendType 不匹配；
- 路由表并发更新与 Resolve。

### Backend 调用

- 正常请求/响应；
- timeout；
- transport unavailable；
- Backend 返回业务错误；
- 256 并发 Backend 调用；
- Registry 并发更新与读取。

### Gateway 集成

- 已认证业务消息路由到 Fake Backend；
- Payload 不被 Gateway 解释/修改；
- 未知 MessageType 返回受控路由错误；
- Backend timeout 返回 `backend_timeout`；
- Backend 不可用返回 `backend_unavailable`；
- Backend 业务错误受控返回；
- Backend 故障后 Session 保持 ACTIVE。

### Metrics

- Backend RPC success/timeout 计数；
- Backend RPC latency count/sum；
- label 不包含 User/Session/Room/Request ID。
