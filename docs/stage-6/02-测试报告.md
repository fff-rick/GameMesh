# Stage 6：测试报告

## 覆盖项

- 两个 Gateway 共享 Registry 时，不同 Gateway 上同账号认证会令后者成为 Owner，并关闭前者连接；
- Memory Registry 验证条件 Release 的 fencing：旧 Lease 不能删除新 Lease；同时验证 TTL 到期后不能继续 Renew；
- Registry 故障时，新认证返回 `presence_unavailable`，但已认证连接持续可收发；
- 全部既有 Stage 0–5 测试保持通过。

## 执行结果

```text
go test ./... -count=1  PASS
go test -race ./...      PASS
go vet ./...              PASS
go build ./...            PASS
```

Redis 实现与 Memory Registry 使用相同的 `Claim/Renew/Release` 契约。单元测试选用内存实现以稳定注入 TTL、fencing 和不可用故障；生产路径通过 go-redis v9 调用 Redis Lua 脚本并使用 Pub/Sub 接收 eviction。
